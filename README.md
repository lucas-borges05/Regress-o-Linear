#  Previsão de Emissões de CO₂ — Regressão Linear

Projeto de Machine Learning desenvolvido para estudar a aplicação de **Regressão Linear** em um problema de previsão de emissões de CO₂ de veículos.

##  Objetivo

Construir um modelo de regressão capaz de estimar as **emissões de CO₂ (g/km)** a partir de uma variável preditora relacionada às características dos veículos.

##  Conceitos aplicados

* Regressão Linear
* Separação entre dados de treino e teste
* Treinamento de modelos com `scikit-learn`
* Análise dos coeficientes e intercepto
* Visualização da linha de regressão
* Avaliação da relação entre variável preditora e variável-alvo

##  Tecnologias

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Jupyter Notebook

##  Abordagem

O projeto explora a relação entre características dos veículos e suas emissões de CO₂, treinando um modelo de regressão linear e visualizando o ajuste entre os valores observados e previstos.

Também são analisados os parâmetros do modelo, permitindo interpretar como a variável de entrada influencia a previsão de emissões.

##  Aprendizados

O projeto reforçou conceitos fundamentais de Machine Learning supervisionado, especialmente a construção, treinamento e interpretação de modelos de regressão.
